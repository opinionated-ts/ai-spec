# What is this repository?

AI coding assistants and tool platforms define their own conventions, formats, and capabilities for concepts such as agents, hooks, plugins, and other aspects of AI-assisted development. While some areas already have established standards, other areas remain fragmented across providers and environments.

`ai-spec` is an **early-stage, community-driven effort** to explore and define an open, opinionated specification for AI-assisted development — a common set of conventions that providers, tools, and development environments can align with.

The project is intentionally starting early, before these conventions are fully defined, so that different ecosystems and their communities can help shape them.

## Goals

* Explore and define common conventions for AI-assisted development where interoperability can provide value.

* Reduce unnecessary inconsistencies between AI coding assistants and tooling platforms.

* Establish conventions that can be implemented across different providers and development environments.

* Build on existing standards and established conventions rather than unnecessarily replacing or duplicating them.

* Work toward an open standard through community discussion, proposals, implementation experience, and iteration.

## Non-goals

* Require providers to adopt a specific implementation.

* Standardize concepts that are already adequately addressed by existing open standards without a clear interoperability need.

## Current status

This project is **very early-stage and under active discussion**. The specification is not yet stable, and its structure, scope, and definitions may change significantly as the community explores different approaches.

At this stage, the goal is not to present a finished standard, but to bring together existing prior art, real-world problems, and perspectives from different AI development ecosystems.

Contributions, criticism, alternative approaches, and implementation experience are encouraged.

See [Discussions](https://github.com/opinionated-ts/ai-spec/discussions) for ongoing conversations, proposals, and open questions.

## Contributing

`ai-spec` is an early-stage project and its direction is still being explored.

Ideas, proposals, feedback, and alternative approaches are welcome as the specification takes shape.
